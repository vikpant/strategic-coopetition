# Examples

Runnable examples for the Coopetition-Gym library.

| Notebook | Topic |
|---|---|
| [`quickstart.ipynb`](quickstart.ipynb) | Single-agent (Gymnasium) and multi-agent (PettingZoo Parallel) APIs, plus the reward-type ablation toggle. |

Open any notebook in Jupyter or run it on Colab. The notebooks install
`coopetition-gym` from PyPI and execute against the public release.
