# caise_2026

Conference paper on the formalisation of interdependence and
complementarity in mixed-motive multi-agent systems, accepted at
[CAiSE 2026](https://caise2026.di.univr.it/) (38th International
Conference on Advanced Information Systems Engineering, Verona,
Italy, June 2026).

## The manuscript

The manuscript is hosted at its canonical sources:

- **arXiv:2510.18802** extended technical report:
  <https://arxiv.org/abs/2510.18802>
- **CAiSE 2026 LNCS proceedings** Springer Lecture Notes in Computer
  Science (link added when the proceedings volume is published).

The conference manuscript is not redistributed from this repository so
that the canonical Springer LNCS version remains the authoritative
formatted source.
