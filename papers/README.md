# Papers

Per-paper artifact bundles. Each subdirectory contains the README,
reproducibility instructions, dataset manifest, and (where applicable)
the datasheet for the released dataset that supports a research
publication. The manuscripts themselves are hosted at their canonical
sources (arXiv preprint and the conference proceedings, respectively),
not in this repository.

## Why no PDFs or LaTeX source here

The conference papers and the technical reports are hosted at arXiv
and at the conference proceedings publishers. This repository contains
the code, dataset manifest, and reproducibility instructions that
support the papers; the manuscripts themselves are linked, not
redistributed, so that the canonical formatted sources remain
authoritative.
