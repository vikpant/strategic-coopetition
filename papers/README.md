# Papers

Per-paper artifact bundles. Each subdirectory contains the README,
reproducibility instructions, dataset manifest, and (where applicable)
the datasheet for the released dataset that supports a research
publication. The manuscripts themselves are hosted at their canonical
sources (arXiv preprint and the conference proceedings, respectively),
not in this repository.

## Conference papers

| Bundle | Status |
|---|---|
| [`caise_2026/`](caise_2026/) | Accepted at CAiSE 2026 (Verona, Italy). Manuscript on arXiv and Springer LNCS. |
| [`neurips_ed_2026/`](neurips_ed_2026/) | Material for the NeurIPS 2026 Datasets and Benchmarks track submission. Manuscript will appear on arXiv at the time of submission. |

## Why no PDFs or LaTeX source here

The conference papers are hosted at arXiv and at the conference
proceedings publishers. This repository contains the code, dataset
manifest, and reproducibility instructions that support the papers;
the manuscripts themselves are linked, not redistributed, so that
the canonical formatted sources remain authoritative.

## Style discipline

All Markdown content in every bundle complies with the authorial style
guide at `coopetition_gym/docs/authorial_style_analysis.md`.
