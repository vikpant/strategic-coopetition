## Dataset

The accompanying dataset is hosted on Hugging Face at
[`vikpant/coopetition-gym-logs`](https://huggingface.co/datasets/vikpant/coopetition-gym-logs).
The Croissant manifest in this directory (`croissant.json`) describes
the dataset structure. `DATASHEET.md` documents the dataset's
construction and intended use following the *Datasheets for Datasets*
template.

## Reproducibility

`REPRODUCE.md` provides step-by-step replication instructions for the
empirical claims of the benchmark. Shared orchestration code lives at
[`coopetition_gym/experiments/`](../../coopetition_gym/experiments/).
